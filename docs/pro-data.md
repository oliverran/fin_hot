# Pro 数据功能说明

## 数据与同步

- 申万行业采用 index_classify 的 SW2021/L1 且 is_pub=1 目录，配合 sw_daily 行情和 PE/PB；不把申万 PE 称为 PE-TTM。
- 宽基历史从 2020 年、申万从 2021 年起补齐。每月首轮核对完整历史，其余任务只回补最近七个自然日；合并按日期覆盖修订。
- trade_cal 提供上交所交易日历。北京时间 19:00 前以此前交易日为应有日期，19:00 后包含当日。日历失败保留旧值，超出日历覆盖不宣称最新。
- 每个指数独立记录成功时间、最后全量核对时间和错误。失败保留既有数据。目录分页不推进时报错，避免静默截断。
- 19:30 同步指数、公司指标和市场背景；09:20 补齐前日两融等延迟数据。两个任务受 TUSHARE_SYNC_ENABLED 控制。

## 页面

- /chronicle/sectors-live：统一申万一级行业收益、近五年正值估值分位（至少252个观测）、月度轮动表、单指数走势。
- /chronicle/market：市场宽度、行业表现、ETF份额和两融。份额变化不是资金净流入；两融缺失交易所不按零计。
- 日报页顶部显示独立市场背景。历史日报仅选该日期之前的交易日，不承诺保持当时版本；历史修订可能更新数值。当前仅补齐最近五个交易日，随后累计。
- /chronicle/companies：已上市公司代码/名称查询，PE-TTM、PB、股息率TTM与总市值。不会根据模糊简称自动匹配新闻主体。
- 管理后台运行页显示数据覆盖及按变化幅度排序的人工核查线索，不自动发稿、推送或调整评分。

## 基金披露持仓

用户指定全部主动股票型与混合型公募，采用在运作的场外基金目录；按基金类型筛选，剔除名称/投资类型明确标记指数、ETF、联接、增强者。这是供应商标签筛选，不能保证识别所有被动产品，页面明确标注。

TUSHARE_FUND_SYNC_ENABLED=true 开启每半小时30个基金份额代码的分批同步。目录每周更新，已处理样本七天后复查，报告期为最近结束季度；每只基金保存进度，中断后继续。未披露、失败与待处理分开统计。

A/C等份额按基金公司与去份额名称近似归组，每组仅取一份披露持仓；产品组不是官方母基金ID。持仓以公告日期过滤未来数据，季报与年报披露范围不一致，不推断未披露仓位、不据此生成历史收益。

基金页展示样本覆盖及共同持仓。全市场首轮同步需多个批次，期间排行不代表完整市场。此前抱团组合规则草案仍待确认，本次没有启用模拟组合交易或回测。
