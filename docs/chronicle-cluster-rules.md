# 抱团组合口径

目标是复盘当时可见的市场共识，不回填今天的赢家。这里的组合都不是任何官方指数，也不作为收益基准；它们只是把「当时市场公认的那批股票」按一个固定规则合起来看形状。成分名单见 `modules/chronicle/cluster-groups.ts`，现算逻辑见 `modules/chronicle/backend/clusters.ts`。

## 组合与名单

- 四代专题各一张走势图：茅指数、宁组合、中特估、AI 算力。
- 更早的四个主题合成「历史祖谱」那张多线图：金融、资源、地产、消费。
- 名单按公开认知起草，固定不变。它只求大致还原当时的共识，不追求与任何指数公司或基金的持仓一致。

## 合成口径

- 初始与全程等权，不调仓；不加权、不按历史权重、不做定期再平衡。
- 上市即纳入、退市即剔除；某个交易日取不到某只成分股的数据，那天就不把它计入，别的照常。
- 用前复权收盘价。含分红与费用的总回报口径不做。
- 每日收益 = 当日有数据的成分股涨跌幅的等权平均；逐日累乘得到组合点位，起点（最早一只成分股上市那天）记 100。

## 另两张图

- 集中度：沪深 300 前十大成分股权重合计（%），按指数公司公布的调仓月；衡量大盘头部的集中程度。
- 相关性：茅指数、宁组合、中特估、AI 算力四个组合日收益的 60 日滚动平均两两相关系数，用共同交易日，样本凑不满一个窗口就不出点。只描述同涨同跌的程度，不当作因果解释。

## 数据来源与刷新

- 成分股的前复权日线取自腾讯证券公开行情接口，落在 `chronicle_quotes`；沪深 300 的月度权重取自本站配置的付费数据服务。
- 每个交易日收盘后刷新一次（`chronicle.clusters`）：先补齐成分股日线，再重算全部组合。个股单只同步失败只记下来，不中断整轮；集中度取不到时保留上一次的数据。

## 局限

- 名单固定，不回填今天的赢家，也不反映历史上的调仓；用它比较的是「同一批股票在不同时间的表现」，不是「当时真实可得的组合收益」。
- 起点取最早一只成分股的上市日，早期成分很少，点位的参考价值有限。
