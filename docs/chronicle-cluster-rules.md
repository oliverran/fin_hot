# 抱团组合规则草案（待确认，尚未启用）

目标是复盘当时可见的市场共识，不回填今天的赢家。

建议第一期采用人工维护的历史专题组合，每一条纳入/移除记录必须附当时发布的公开来源和日期。宁组合、白酒、中特估、AI 算力分别建立独立组合，不将主题指数直接冒充抱团持仓。

建议口径：初始等权；每季度首个交易日按已确认名单调仓；只使用调仓前已公开的信息，下一交易日收盘实施。记录成分生效区间，保留退市与被剔除证券；停牌不假设可交易，复牌后按规则执行。价格序列与分红、复权、交易费用必须明确，缺少必要历史数据时不计算收益。

建议同时展示：组合相对沪深 300 的收益、最大回撤、成分集中度、成分变更时间线。组合相关性先使用共同交易日的 60 日收益，样本不足留空；不把相关性作为因果解释。

需要你确认：首个专题；初始成分和依据；等权还是历史权重；季度还是事件触发调仓；价格回报还是含分红总回报；交易费用假设。确认前页面不展示模拟收益。
