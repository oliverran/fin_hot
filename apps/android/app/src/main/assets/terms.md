# FinHOT 使用规则

| 项 | 值 |
|---|---|
| 版本 | 1.0 |
| 生效日期 | 2026 年 11 月 18 日 |

页首说明：

> 本规则适用于 FinHOT 网站、iOS 和 Android 客户端，以及 RSS、公开 API 和 MCP 提供的内容。

## 1. 阅读与研究

你可以使用 FinHOT 进行个人阅读和组织内部研究。引用资料时请保留来源名称、原文链接和日期。原文、图片和行情数据的权利归各权利人所有，第三方来源的使用条件仍然适用。商业转载、对外分发和将内容纳入对外产品，请事先向相关权利人取得许可。

## 2. 摘要与行情

FinHOT 聚合公开信源，借助模型生成中文摘要、精选理由和简报。摘要可能遗漏上下文，涉及投资或交易的事实请核对原始公告。图表展示各自标注期间的历史数据，可能延迟或更正。内容供阅读研究，不构成投资建议。

## 3. 访问接口

RSS、公开 API 和 MCP 支持匿名读取。请遵守响应中的缓存期限，遇到访问频率限制时按 Retry-After 指定时间重试。

## 4. 纠错、授权与下架

请通过[官网反馈页](https://www.finhub.website/feedback)提供文章或图表链接、需要更正的位置和依据。权利人可以通过同一渠道提出下架或调整展示方式的请求。
