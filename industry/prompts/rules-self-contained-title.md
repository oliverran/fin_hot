
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：机构名 / 产品名 / 基金或股票名称与代码 / 项目名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是产品代码 / 代号 / 没信息量的 teaser（如 "510300"、"稳了"、"重要公告"）时，结合【来源】和正文把主体补进标题。例：原标题 "159915" + 来源 "深交所：基金公告" → "易方达创业板ETF（159915）调整申购安排"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体产品时，用上位词（如"一只宽基指数 ETF"）兜底，绝不凭"行业常识"编一个具体产品名 / 代码 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / Strategy 这类解释、分析、解读或策略标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的产品、机构或新数据，就改写成“发行 / 推出 / 上线 / 下调评级”。只有原标题明确宣布了发行、推出、成立或评级调整，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的机构、产品、项目名。
   例：原标题 "Why the bond market is repricing rate cuts" + 来源和正文明确是中金公司 → "中金公司解读债市为何重定价降息预期"，不能写成 "中金公司下调债券评级"。
   例：原标题 "How to read a fund's quarterly report" + 来源和正文明确是易方达基金 → "易方达基金如何读懂基金季报"，不能只写成缺主体的 "如何读懂基金季报"。
6. 本条的动作和背景里的旧发布要分清：原文把发行写成过去的事（“在上周的发布会上，我们发布了 …”“上季度我们成立了 …”“此前已募集完成”），本条是在解读、演示或再次介绍时，标题写解读、演示或介绍，把发行交代成此前的事；不能写成“发行 / 推出 / 成立”，否则读者会当成今天的新闻。只有原文明确某项产品是现在才发行或开放申购，才对那一项用对应动作。
   例：正文 "在上周的发布会上，我们发布了 X 基金 … 下面看它怎么运作" → "X 基金演示上周发行的产品如何运作"，不能写成 "X 基金发行新基金"。
